# 🌍 Eco-Track – Carbon Footprint Calculator

Track, analyze, and reduce your carbon emissions.

---

## 📖 Overview

Eco-Track is a carbon footprint calculator designed to help individuals understand the environmental impact of their daily activities. By collecting user inputs related to lifestyle and energy usage, the application estimates carbon emissions and promotes sustainable living.

---

## ❗ Problem Statement

Climate change is accelerating due to increasing carbon emissions from human activities. Many individuals are unaware of how their daily habits contribute to carbon emissions or lack tools to measure them effectively.

---

## 💡 Solution

Eco-Track provides a simple and interactive platform to calculate carbon emissions based on user activity data, helping users identify major emission sources and make environmentally responsible decisions.

---

## 🚀 Features

- Carbon footprint calculation  
- Category-wise emission analysis  
- User-friendly interface  
- Real-time results  

---

## 🛠️ Tech Stack

- Frontend: Streamlit, HTML, CSS  
- Backend: Python  
- Libraries: NumPy, Pandas  
- Tools: Git, GitHub  

---

## 🔄 Workflow

1. User enters daily activity data  
2. System processes inputs  
3. Emissions are calculated  
4. Results are displayed  

---

## ⚙️ Installation

### Prerequisites

- Python 3.8+
- Streamlit

### Steps

```bash
git clone https://github.com/saro0923/Eco-Track--Carbon-Footprint-Calculator.git
cd Eco-Track--Carbon-Footprint-Calculator
pip install -r requirements.txt
streamlit run app.py
```

## ▶️ Usage

- View results
